What is FSCSS?

A lightweight CSS preprocessor that adds shorthand syntax, variables, reusable blocks, arrays, and even natural-language pattern() matching. It compiles to plain CSS.

Features Showcase

  • Variables & design tokens
  • @define mixins
  • Semantic pattern() matching
  • Arrays & @random()
  • Zero-runtime production builds via CLI
